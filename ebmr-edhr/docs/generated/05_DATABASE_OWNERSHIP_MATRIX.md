## Store-level rules

- PostgreSQL — authoritative regulated GxP state, audit stream, record versions, outbox, idempotency (Docs 69/70/73).
- MariaDB (Frappe) — framework, UI configuration, authoring drafts, approved projections. Never authoritative for released/regulated truth (Doc 71 MDB-FR-002).
- Object storage — immutable, hash-addressed evidence with WORM/retention policy (Doc 72).
- Redis / search / analytics — rebuildable read models; never a regulated decision source (Doc 75).
- Temporal — orchestration state only (Doc 74).
- Edge local buffer — pre-authoritative until accepted through an integration command (Docs 43–47).
- ERP — commercial/financial truth per Doc 48 ownership matrix; never the source of QA release.
