## Rules
- No migration before the entity exists in the data model catalogue (SCH-FR-001).
- Only the owning service migrates its own tables.
- Regulated rows are never rewritten by a migration without an approved change record.
- Every migration records execution evidence (plan, counts before/after, duration, operator).
