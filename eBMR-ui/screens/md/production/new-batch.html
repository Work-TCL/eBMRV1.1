Why the draft revision is not selectable

Rev D exists and is under review, but it has not been approved. Issuing work against an unapproved master is one of the most common findings in an inspection — so the system does not offer it, rather than warning about it afterwards.

What issuing actually does

A device build order draws its content from the released Device Master Record. Every unit built under it gets its own Device History Record, and the DHR must show that the unit was built to that exact revision.

This is where genealogy is created

The link between this build order and these specific lots is written now and never changes. If a supplier recalls one lot two years from now, this link is how you find every affected unit in seconds instead of weeks.

What the system checks on each lot, before it will accept it

  • Approved status — a quarantined or rejected lot cannot be allocated at all.
  • Expiry and retest date — must remain valid through the planned end of the run, not just today.
  • Quantity on hand — enough must physically exist, or the order is short before it starts.
  • Correct material — the lot must belong to the material the bill of materials names.
