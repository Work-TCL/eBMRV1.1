Status here is the material's approval as an item type. Each delivered lot is approved separately — an approved material can still have a rejected lot.

Material vs lot — the distinction that matters

Material (this screen)

"Magnesium stearate, MAT-1003" — the kind of thing. Defined once, used forever.

Lot (recorded during production)

"LOT-A2291, received 12 Jul, expires Mar 2028" — a specific delivery. Each lot carries its own status, expiry and test results.

Genealogy links a finished batch to the exact lots used — so if a supplier recalls one lot, you can find every affected batch in seconds.
