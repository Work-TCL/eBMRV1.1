What the tolerance column does

Tolerance is what makes dispensing enforceable. Magnesium stearate above is 1.800 kg ±5.0% — so the operator must land between 1.710 and 1.890 kg. Weigh 1.895 kg and the system refuses to accept it and opens an exception; there is no "close enough" path. Set tolerances too wide and the control is meaningless; too narrow and production stops constantly.
