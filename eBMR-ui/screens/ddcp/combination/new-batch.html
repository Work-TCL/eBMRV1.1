Why the draft version is not selectable

v1.5 exists and is under review, but it has not been approved. Issuing work against an unapproved master is one of the most common findings in an inspection — so the system does not offer it, rather than warning about it afterwards.

What issuing actually does

A combination product order is unusual: it consumes a finished drug batch and a finished device lot, each already released under its own rules. The integrated master governs how they are joined, and Part 4 requires both rule-sets to be satisfied — you cannot release on the strength of one.

This is where genealogy is created

The link between this final assembly order and these specific lots is written now and never changes. If a supplier recalls one lot two years from now, this link is how you find every affected unit in seconds instead of weeks.

What the system checks on each lot, before it will accept it

  • Approved status — a quarantined or rejected lot cannot be allocated at all.
  • Expiry and retest date — must remain valid through the planned end of the run, not just today.
  • Quantity on hand — enough must physically exist, or the order is short before it starts.
  • Correct material — the lot must belong to the material the bill of materials names.
